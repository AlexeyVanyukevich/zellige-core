## Decisions this plan adds to the spec

- **The keyboard journey starts from the `plain` caption**, an `h3` that is not focusable, as the
  radio group's does, and runs in the first theme of `THEMES`.
- **Baselines** are made with `./run test --update-snapshots -g checkbox`, a title grep, because a
  positional argument filters by file and never reaches `screenshots.spec.ts`.
- **The dataset adds a row** for the disabled label's colour against `--zl-ink-faint`.
